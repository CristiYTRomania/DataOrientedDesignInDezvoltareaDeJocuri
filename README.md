Acesta este repozitoriul de GitHub în care îmi voi face proiectul la materia "Data Oriented Design în dezvoltarea de jocuri"

## Controls

- T - ToggleMonsterMode
- Plus - Add 1000 particles
- Minus - Remove 1000 particles
- N - Add 5 enemies
- M - Remove 5 enemies
- R - Restart game if finished or lost
- Tab - Switch OOP/DOD
